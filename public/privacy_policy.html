Politique de confidentialité

Conforme RGPD · 100 % local

Application : LoadLess — Gérez votre foyer en équité
Version : 4.2
Dernière mise à jour : 2026-05-11

1. Données collectées

LoadLess ne collecte aucune donnée personnelle à des fins commerciales ou analytiques. Les seules données stockées sont celles que vous saisissez vous-même :

  • Adresse e-mail (authentification uniquement)
  • Tâches, transactions budgétaires, liste de courses, événements de calendrier, menus
  • Messages du chat (chiffrés de bout en bout — illisibles par quiconque d'autre)

2. Stockage

Toutes les données sont stockées dans votre instance Supabase (cloud ou auto-hébergée). Aucune donnée n'est envoyée à des tiers. Aucun tracker, aucune régie publicitaire, aucun SDK analytique n'est intégré.

3. Chiffrement

Les messages du chat sont chiffrés de bout en bout (ECDH P-256 + AES-GCM 256 bits). Les sauvegardes exportées sont chiffrées avec AES-GCM 256 bits / PBKDF2.

4. Permissions Android

L'application ne demande aucune permission réseau au-delà de l'accès à votre instance Supabase, et aucune permission matérielle (caméra, microphone, localisation, contacts).

5. Droit à l'effacement (RGPD Art. 17)

Vous pouvez supprimer intégralement votre compte et toutes vos données depuis Paramètres → Zone de danger → Supprimer mon compte. La suppression est immédiate et irréversible.

6. Contact

Pour toute question : consultez le fichier README.md de votre instance auto-hébergée, ou contactez l'administrateur de votre déploiement.

7. Open Source

Le code source de LoadLess est auditable. Il ne contient aucune dépendance à Google, Meta, Apple, Amazon ou Microsoft.
